# tenhou_se

天凤（Tenhou）自定义角色语音（SE）静态托管仓库，部署于 Cloudflare Pages（`https://tenhou.nivalis.is`）。

## 角色列表
- **冬馬かずさ（冬马和纱）**：`https://tenhou.nivalis.is/kazusa.json`

## 使用方法
1. 打开天凤网页版 → **设置 → SE 设定** → 取消勾选「標準のSE」→ 填入 `https://tenhou.nivalis.is/kazusa.json`。
2. 如需同一动作每次触发随机播放不同语音，可安装仓库内的通用油猴脚本 [tenhou_random_se.user.js](./tenhou_random_se.user.js)。
